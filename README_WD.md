# TustPortal — Windows 版本说明

> 本文档为 Windows 版本的独立说明。macOS 版本说明请参阅项目根目录的 README.md。

## 功能概述

天科大校园网自动登录桌面客户端（Windows 版）。驻留系统托盘，每隔 20 秒检测网络状态并自动登录校园网认证门户。

- **首次启动弹窗**：首次运行时会打开设置窗口并询问是否开启开机自启
- **左键托盘图标**：单击系统托盘图标可直接打开设置窗口（右键仍为菜单）
- **开机自启**：支持注册到当前用户的启动项，可在设置中随时开关
- **免管理员安装**：提供 NSIS 安装包（`.exe`），无需管理员权限即可安装到当前用户目录

## 系统要求

- Windows 10 版本 1803 或更高版本 / Windows 11
- 具备 WiFi 适配器（用于 SSID 检测；也可在设置中开启"忽略 SSID 检测"以支持有线网络）

## 安装与首次使用（零基础教程）

### 第一步：下载

从 Release 页面下载安装包。你会看到两个文件：

| 文件名                       | 选哪个？                                              |
| ---------------------------- | ----------------------------------------------------- |
| `TustPortal-setup_xxx.exe` | **选这个，推荐！** 双击就能装，不需要管理员密码 |
| `TustPortal_xxx.msi`       | 管理员安装用，普通用户忽略                            |

> 如果不会选，就下载 `.exe` 那个。

### 第二步：安装

1. 双击下载的 `TustPortal-setup_xxx.exe`
2. 一路点 **"下一步"**，全部默认即可
3. 最后点 **"完成"**

安装完成后程序会自动启动。

### 第三步：找到程序

程序启动后不会弹出大窗口，而是缩在屏幕右下角的**系统托盘**里。

> 如果托盘区域看不到，先点一下任务栏上的 **`^`** 小箭头（"显示隐藏的图标"），在里面就能找到。

### 第四步：输入账号密码

**首次运行时，设置窗口会自动弹出。** 如果没有弹出来，右键点托盘图标 → 选 **"设置…"**。

在设置窗口中：

| 字段   | 填什么                                  |
| ------ | --------------------------------------- |
| 用户名 | 你的学号或工号                          |
| 密码   | 你的校园网密码                          |
| 运营商 | 选**校园网**或 **中国联通** |

填好后点 **"保存凭据"**。

### 第五步：选择是否开机自启

保存凭据后会弹出一个提示窗口：

> **"是否开启开机自动启动？"**

- 点 **"是"** → 以后每次开机，程序会自动在后台运行
- 点 **"否"** → 以后需要手动从开始菜单打开程序

> 这个设置以后可以随时改。打开程序 → 点击 **"连接"** 标签页 → 找到 **"开机自动启动"** 开关。

### 第六步：确认程序在正常工作

打开程序，查看设置窗口顶部的状态栏：

| 你看到什么                              | 含义                                              |
| --------------------------------------- | ------------------------------------------------- |
| 🟢`TUST-5G` \| `10.x.x.x` \| 校园网 | **一切正常！** 已连接校园网，程序在后台守护 |
| 🟢`CU_TUST` \| `10.x.x.x` \| 校园网 | 正常，已连接联通校园网                            |
| ⚪`未检测到WiFi` \| `无IP`          | 还没连上 WiFi 或有线，连上后会自动登录            |

当状态栏显示"校园网"绿色标签时，程序会在检测到需要登录时自动完成认证。你不需要做任何操作。

## 日常使用

### 你需要做什么？

**基本不需要做什么。** 只要程序在运行（托盘里有图标），它会自动检测网络并在需要时登录。你可以把它忘掉。

### 托盘图标怎么用

| 操作                        | 效果         |
| --------------------------- | ------------ |
| **左键单击** 托盘图标 | 打开设置窗口 |
| **右键单击** 托盘图标 | 弹出功能菜单 |

菜单说明：

| 菜单项       | 功能                         |
| ------------ | ---------------------------- |
| 触发登录     | 立即手动登录一次             |
| 暂停自动登录 | 暂停或恢复后台自动登录       |
| 日志         | 查看登录记录（排查问题时用） |
| 设置…       | 打开设置窗口                 |
| 退出         | 完全关闭程序                 |

### 设置项说明

| 设置项         | 作用                                                                                     |
| -------------- | ---------------------------------------------------------------------------------------- |
| 自动登录       | 总开关。关闭后程序不再自动检测和登录                                                     |
| 开机自动启动   | 是否在 Windows 启动时自动运行（仅 Windows 有此选项）                                     |
| 忽略 SSID 检测 | 开启后，只要 IP 是 `10.x` 就尝试登录，不检查 WiFi 名称。**有线网用户请打开这个** |

## 常见问题排查

### 程序在哪？我找不到它了

按 `Win` 键，输入 `TustPortal`，点图标启动。如果已经在运行，去任务栏右下角找托盘图标。还是找不到？点任务栏 `^` 小箭头展开隐藏图标。

### 一直显示"未检测到WiFi"

- 确认你的电脑已连接 WiFi
- 如果你用的是**有线网（网线）**：打开设置 → 切换到 **"连接"** 标签页 → 打开 **"忽略 SSID 检测"**
- 如果 WiFi 已连接但仍不显示：重启程序试试

### 校园网断了，程序没自动登录

1. 确认托盘图标还在（程序没有退出）
2. 确认设置里"自动登录"开关是**打开**的
3. 确认已保存了正确的用户名和密码
4. 实在不行：右键托盘图标 → **触发登录**，手动试一次

### 提示"登录失败"

- 检查用户名和密码是否填写正确
- 确认运营商选对了（校园网 还是 中国联通）
- 如果密码最近改过：打开设置 → 重新输入新密码 → **保存凭据**

### 我选择了"否"（不开机自启），现在想改成"是"

打开设置 → 切换到 **"连接"** 标签页 → 打开 **"开机自动启动"** 开关即可。

### 电脑重启后程序不在了

- 如果你选了开机自启：它应该在托盘里。展开隐藏图标找找（点 `^`）
- 如果你没选开机自启：从开始菜单搜索 `TustPortal` 手动启动
- 推荐打开开机自启，这样就不用每次手动启动

### 如何卸载

1. 右键托盘图标 → **退出**
2. 打开 Windows 设置 → **应用** → **已安装的应用**
3. 搜索 `TustPortal` → 点击三个点 → **卸载**
4. 删除残留数据（可选）：按 `Win + R`，输入 `%AppData%\com.tust.portal`，回车，删除整个文件夹

## 开发环境搭建

### 前置依赖

- [Rust](https://www.rust-lang.org/) (stable)
- [Node.js](https://nodejs.org/) >= 18
- [pnpm](https://pnpm.io/)
- **Visual C++ 生成工具**（Tauri 编译所需）
  - 安装 [Visual Studio Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/)
  - 在安装器中选择**"使用 C++ 的桌面开发"**工作负载

### 快速开始

```powershell
# 安装前端依赖
pnpm install

# 启动开发模式（热更新）
pnpm tauri dev

# 构建生产版本（生成 .msi 和 .exe）
pnpm tauri build
```

构建产物位于：

- NSIS 安装包: `src-tauri\target\release\bundle\nsis\`
- MSI 安装包: `src-tauri\target\release\bundle\msi\`

## 与 macOS 版本的差异

| 项目           | Windows                        | macOS                           |
| -------------- | ------------------------------ | ------------------------------- |
| 首次启动       | 自动打开设置窗口               | 无窗口，仅托盘                  |
| 托盘左键       | 打开设置                       | 无动作（显示菜单）              |
| 开机自启       | 支持（注册表启动项）           | 不支持                          |
| WiFi SSID 检测 | `netsh wlan show interfaces` | `ipconfig` / `networksetup` |
| 安装包         | `.exe` (NSIS) + `.msi`     | `.dmg`                        |

## 隐私声明

本软件仅为自动登录脚本，账号与密码保存于本地应用数据目录（`%AppData%\com.tust.portal\credentials.json`），以明文存储，不会被上传到云端。请自行保护好个人设备安全。

使用本软件即代表您同意[天津科技大学校园网管理办法](http://10.10.102.50/a09.htm?ip=10.0.0.0&vlan=0&ssid=&areaID=)（该链接仅能在校园网内打开）。
